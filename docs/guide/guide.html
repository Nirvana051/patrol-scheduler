1认识巡检调度系统

巡检调度系统是运行在现场电脑上的巡检操作台：它通过 certaintyX 云端接口指挥机器狗按路线巡检，到每个巡检点拍一张 360° 全景，交给视觉大模型（VLM）判断「是 / 不是」，再把结论用语音播报出来，全过程留档。

定义巡检点去哪儿、看什么、
怎么判、怎么播报
→
分段下发起点 → 巡检点 1 →
巡检点 2 → …
→
到点检查拍全景 → 裁切
→ VLM 判是/不是
→
播报与留档语音播报；图片、
结论、事件全部入库

为什么要「分段下发」：机器狗走一条路径时中途不会停。所以系统把每个巡检点单独下发一段，机器人到点后才能停下来拍照判读，再下发下一段。

两个必须分清的名词

含义来自
导航航点地图自带的点，编号 1、2、12…，带坐标和连通关系机器人的地图（只读）
任务航点你定义的巡检点：落在某个导航航点上，并带有检查问题（prompt）、全景角度范围、答案模版、参考图本系统

桌面版的构成

安装包里已经带好了程序运行需要的一切（固定版本的 Python 3.12 运行时、全部依赖、ffmpeg 抓图工具、中文字体），不需要另外安装 Python 或其他软件。程序由两部分组成：

  • 窗口与托盘图标：你看到的界面。关闭窗口只是把它收进托盘，巡检和定时计划照常运行。
  • 后台服务：真正指挥机器人的部分，随窗口自动启动、自动停止。它只在本机 127.0.0.1 上提供服务，局域网里的其他电脑访问不到。

2安装前准备

2.1 电脑要求

项目要求
操作系统Windows 10 或 Windows 11，64 位（x64）
磁盘空间安装后约 700 MB；另外为巡检图片与数据库预留空间（每次检查约 0.1–0.2 MB 图片）

信息示例说明

密钥要保管好密钥只保存在本机的后台服务里，界面上永远只显示掩码。不要把密钥发到聊天群或写在共享文档里。

3安装

3.1 运行安装包

  1. 拿到安装包 PatrolScheduler-0.8.0-win-x64.exe（约 197 MB），双击运行。
  2. 若出现蓝色的「Windows 已保护你的电脑」提示：点更多信息，再点仍要运行。
    这是因为当前安装包还没有做代码签名，属于正常现象；签名后这个提示会消失。
  3. 安装选项：保持默认的「仅为我安装」，点下一步。
    选「为使用这台电脑的任何人安装（所有用户）」需要管理员权限，一般不需要。
  4. 选定安装位置：默认装在当前用户目录下（所需空间约 690 MB），一般不用改；要换位置点浏览。然后点安装，大约半分钟装完。
  5. 完成：保持勾选「运行 PatrolScheduler」，点完成，程序会自动启动。

3.2 装好之后

  • 开始菜单和桌面上都会出现「巡检调度系统」快捷方式。
  • 默认安装位置：%LOCALAPPDATA%\Programs\PatrolScheduler
  • 在 Windows「设置 → 应用 → 已安装的应用」里显示为 PatrolScheduler 0.8.0。

4第一次启动

第一次启动会弹出「第一次启动」提示框，窗口直接停在设置页，等你填写云端连接信息。点知道了关闭提示框。

还没准备好真机信息？可以先在托盘菜单里勾选「仿真模式」，用内置的仿真机器狗把所有功能试一遍（见第 5 章）。仿真数据与真机数据分开保存，互不影响。

4.1 托盘图标在哪里

程序运行时，任务栏右下角的通知区域里有一个蓝色圆形图标。Windows 默认会把新图标收在「^」（显示隐藏的图标）里，点开就能看到。

  • 左键单击托盘图标：打开窗口。
  • 右键单击托盘图标：打开托盘菜单（各项说明见 §9.1）。
让图标常驻任务栏Windows 11：设置 → 个性化 → 任务栏 → 其他系统托盘图标，打开「PatrolScheduler」。Windows 10：把图标从「^」里拖到任务栏上。

4.2 关闭窗口 ≠ 退出程序

点窗口右上角的 × 只是把窗口收进托盘，巡检与定时计划会继续执行。第一次这样做时右下角会弹出通知提醒你。要彻底退出，请用托盘菜单里的退出（会先停下机器人）（见 §9.2）。

5先在仿真模式里试一遍

仿真模式会在本机启动一只「仿真机器狗」：不需要机器人、不需要密钥，不会让任何真实设备动起来。建议第一次使用时先在这里把整个流程走一遍。

  1. 右键托盘图标，勾选仿真模式。几秒后页面自动刷新，右下角弹出「已切到仿真模式」的通知。
  2. 确认窗口左下角显示绿色的 MOCK · 仿真，顶栏第一个灯是绿色的「在线」。
  3. 在总览页点📷 抓一张全景，右下方会出现一张合成的 360° 全景图，图上的中文标注应清晰可读。
  4. 按第 8 章的步骤建任务航点、建任务并执行，在执行监控里观察分段进度与检查结果。
仿真里有现成的演示地图仿真机器狗自带一张演示地图（含导航航点、合成的全景画面：配电箱、安全出口、地面方格、消防栓柜、立柱等），可以直接拿来练习划定角度、写检查问题。想一键灌入演示数据，见附录 B 末尾的命令。

试完后，在托盘里取消勾选「仿真模式」即可回到真机模式；仿真里建的数据保留在仿真自己的数据目录里，下次勾选时还在。

6接入真机

先退出仿真模式，再填写真机信息仿真模式与真机模式各有一套独立的设置和数据。请先右键托盘图标、取消勾选「仿真模式」（托盘菜单第三行显示「当前：真机模式」），再到设置页填写。在仿真模式里填写的地址和密钥不会用于真机。

6.1 填写云端连接

  1. 托盘菜单 → 打开设置，或在窗口左侧点⚙ 设置。
  2. 在「云端连接（改动会重建连接）」一栏填写：云端地址、机器人别名、API 密钥。
  3. 在「抓图与执行」一栏把抓图源改为 rtsp。
  4. 点右上角保存。系统会立即用新地址重建云端连接：右侧「当前适配器」的模式随即变为 REAL 真机，几秒内左下角也会变为橙色 REAL · 真机。
  5. 机器人在线时顶栏「在线」灯为绿色；机器人未开机或网络不通时显示「离线」或「云端不可达」。
填写之前看到 MOCK 是正常的在真机模式下还没填写云端地址时，地址一栏显示的是默认占位值 http://127.0.0.1:18443，左下角会显示「MOCK · 仿真」、顶栏显示「云端不可达」。填好真实地址并保存，几秒内就会变为 REAL · 真机。
优先级设置页右上角写着「此处设置 > config/.env > 默认值」。桌面版只需要在设置页里改，不需要编辑任何配置文件。

6.2 执行前置检查

在总览页点↻ 刷新状态，系统会列出七项执行前置检查。七项全部通过才能执行任务：

检查项不通过时怎么办
云端网关可达检查网络、云端地址是否填对
机器人在线确认机器人已开机并联网
无急停指令点提示旁的「取消急停」
ROS 可用机器人端 ROS 未运行，读到的都是旧数据；联系机器人维护人员
定位就绪按 §6.3 做「② 启动设备」与「④ 定位」
云端无进行中的任务若提示中路径为空（通常是刚做过定位的残留），点「停任务」；若是别人下发的任务，等它结束
控制权可用现场有人在操作机器人，等对方放手

抓图源：rtsp 是首选；若 8554 端口被防火墙挡住，改为 hls（抓帧更快但画面会落后 2–3 秒）。

6.3 机器人初始化（真机必需，一次性）

在总览 → 机器人初始化里按顺序做一次（机器人不重启、不丢定位就不用重做）：

  1. ② 启动设备：在机器人上启动导航、定位等模块。漏掉这一步，任务会「下发成功但机器人不动」。
  2. ④ 定位：选择地图，再选择机器人此刻真实所在（或最接近）的导航航点，点定位。最多等 20 秒；偏差超过 3 米判为失败。
  3. 顶栏「定位」灯变绿即完成。
定位初值必须是机器人真实所在的航点选错了，要么定位失败，要么定位到错误的位置，之后巡检会朝错误方向走，有物理风险。

6.4 机头校准（真机第一次使用时做一次）

全景图上机器人正前方对应哪一列，需要标定一次，任务航点编辑器里「相对机头 ±N°」的读数才准：

  1. 让机器人朝向一个已知的地标停下。
  2. 设置页 →「机头校准（FORWARD_DEG）」→ 点📷 抓一张全景。
  3. 把画面上的蓝色虚线拖到机器人正前方所在的位置，点保存为 FORWARD_DEG。

7配置视觉判读（VLM）与语音播报（TTS）

7.1 视觉判读（设置 → VLM 视觉判读）

提供方用法
mock不调用模型，交替回答「是 / 不是」。用于打通流程或演示（默认值）
qwen阿里通义千问（DashScope）。OpenAI 兼容地址留空即可；模型填 qwen3.5-flash（图片被拒时换 qwen3-vl-plus / qwen-vl-max）；API Key 填 DashScope 的 sk-…
openai_compat任何 OpenAI 兼容服务：本机 Ollama（http://127.0.0.1:11434/v1，模型如 qwen2.5vl:7b）、vLLM、LM Studio、OpenAI
anthropicAnthropic 官方接口：填 Anthropic API Key 与模型名

填好后点保存，再到任务航点编辑器的「试问 VLM」里点用参考图验证（见 §8.2），这一步不会让机器人动。

「附整张全景」= 除了裁切图外再发一张带角度标注的整图，模型能看到更多上下文，但每次调用更贵。

7.2 语音播报（设置 → TTS 播报）

引擎决定怎么把文字变成声音：edge = 微软在线合成，音色好，需要联网（默认）；none = 不合成，文字交给网页朗读或发给机器人本地离线合成；command = 调用命令行 TTS 程序（高级用法）。汇出决定在哪里播放，可以多选，用英文逗号分隔：

汇出播放位置
robot机器狗自带的扬声器（推荐真机使用；需要机器人固件 2026-09-14 或更新）
browser本程序窗口（也就是这台电脑的扬声器）。网页需先点一下顶栏「🔊 声音」解除自动播放限制
http项目自带的播报服务（旧固件没有播报接口时的替代方案，需要实施人员部署）
webhook把播报内容 POST 到指定地址
推荐的真机组合 汇出填 robot,browser：机器狗现场播报，同时电脑上也能听到。
引擎选 edge：音色好，推不成时会自动退回文字由机器人自己念；如果调度电脑不能上外网，选 none，由机器人离线合成。
机器人音量设一次，机器人会记住；播完再继续保持 0（边走边播）可以节省时间。

设置页「当前适配器」卡片里可以输入一句话点▶ 试听 TTS，🐕 机器人播报状态可查看机器人端的声卡、队列与音量，⏹ 打断清空播报队列。

8做一次完整巡检

以下步骤在仿真模式与真机模式下完全一样。建议先在仿真里练熟。

8.1 同步地图（每张地图一次；重新建图后要重做）

左侧地图与导航航点 → 选择地图 → 同步。画布上会显示导航航点、连通关系与机器人的实时位置。检查两个数字：航点数是否正确；连通块是否为 1（大于 1 说明地图拓扑断开，跨块的路段会走不通）。

在画布上点某个导航航点，可以直接「添加为任务航点」「设为定位初值」或「设为路线起点 / 终点」。

8.2 定义任务航点（巡检点）

左侧任务航点 → ＋ 新建任务航点（或在地图上点导航航点 →「添加为任务航点」）。编辑器右半边的全景角度编辑器是核心操作：

  1. 点📷 抓一张作参考图（或上传一张）。建议先让机器人真的走到这个点再抓，看到的就是它到点后的视野。
  2. 在图上拖动两条黄线圈出要检查的方位范围：最左 0°、中间 180°、最右 360°；起点大于终点（如 330°→30°）表示跨越左右接缝，系统会自动拼接。
  3. 写检查问题（prompt）：必须是能用「是 / 不是」回答的具体问题，例如「画面中间的红色消防栓柜门是否关好？」「地面黄色方格区域内是否有物品堆放？」。
  4. 填答案模版：选择回答「是」还是「不是」算通过（例如「门是否关好」期望「是」，「通道是否被占用」期望「不是」）；再写通过 / 不通过 / 无法判断三句播报，可用 {name}（航点名）、{answer}（模型回答）占位，每句后面的 ▶ 可以试听。
  5. 点保存后，在编辑器右下的「试问 VLM」里点用参考图（或现抓一张）：立即看到裁切图、模型原始回复、判读结果和将要播报的那句话。不满意就改问题或收窄角度，反复试，这一步不会让机器人动。

8.3 建任务

左侧任务规划 → ＋ 新建任务：选择地图、起始点，按顺序加入任务航点（上下箭头调整顺序）。

  • 起始点选「自动」= 执行时按机器人当前位置取最近的航点；指定具体航点则每次都从它出发（适合总从充电位或门口出发）。
  • 执行选项都有默认值，不确定就别改。常用的几项：到点稳定（默认 2 秒，机器人到点后还在晃就加大）、每段超时（默认 600 秒）、结束后返回起点（默认关）、执行前要求定位就绪（默认开，真机务必保持开）。
  • 点路线预览各段路径与总长，走不通的段会标红。

8.4 执行与看护

点▶ 执行：系统先做一次前置检查（不通过会直接列出原因），真机模式还会再确认一次。之后在执行监控里查看：

  • 分段进度：每段依次显示 已下发 → 导航中 → 已到达 → 检查中 → 完成。
  • 检查结果：带角度标注的全景、裁切图、模型回复、判读结论与播报文本（可重放）。每条结果可以人工复核（判通过 / 判不通过 / 撤销），统计按复核后的结果计算。
  • 事件时间线：云端与系统事件合在一起，可导出 CSV。
人工干预按钮作用
⏸ 暂停当前段走完后停下；点「▶ 继续」接着走
⏭ 跳过当前航点停掉这一段，从当前位置重新规划下一段
■ 中止停止任务，并把本次执行标记为已中止

执行失败或中止后，执行详情右上角会出现「↻ 从『某航点』重跑剩余航点」，只走没做完的部分。

顶栏「⚠ 急停」不是硬件急停它让机器人端持续下发停止指令，现场遥控仍可能与它竞争，而且机器人收到后还会滑行 5–7 秒才停住。要确保机器人绝对不动，请按机器人身上的物理急停按钮。

8.5 定时执行

任务规划 → ⏰ 定时：可设「每天固定时刻」（如 07:30,19:30）或「每 N 分钟」。到点时如已有执行在跑，会跳过并记一条事件；执行前照常做前置检查。定时计划只在程序运行时生效（窗口收进托盘也算运行），建议配合「开机自启」使用（§9.3）。

9日常使用

9.1 托盘菜单

9.2 退出程序

右键托盘图标 → 退出（会先停下机器人）：

  • 没有巡检在执行：程序在几秒内退出。
  • 有巡检正在执行：先弹出确认框。点中止并退出，系统会中止本次执行、让机器人停下，再退出（实测约 2 秒；最长等 40 秒）。点取消则什么都不做，巡检继续。
不要用任务管理器强行结束强行结束不会让机器人停下。确认框偶尔会被别的窗口挡住：把鼠标移到任务栏上的 PatrolScheduler 图标，在弹出的缩略图里点「退出」那一个即可。

9.3 开机自启

托盘菜单勾选开机自启后，每次登录 Windows 都会自动启动，并沿用上次的模式（仿真 / 真机）。需要定时巡检的电脑建议打开。取消勾选即关闭。

9.4 状态与自检

托盘状态…，或设置页下方的「系统自检」，可以看到版本、数据库、后台线程、媒体占用和「运行环境」。正常应显示：

Python 3.12.13 · 自带运行时 runtime · ffmpeg 有 · 中文字体 NotoSansCJKsc-Regular · win32

9.5 数据、日志与备份

所有数据保存在 %APPDATA%\PatrolScheduler\ 下（在资源管理器地址栏输入这串路径即可打开）：

位置内容
data\真机模式的数据库（scheduler.db）、巡检图片（media\）、后台日志（logs\app.log）
data-mock\仿真模式的数据，结构同上
logs\窗口与后台服务的启动日志：desktop.log、backend.out、mock.out
desktop.json记住上次是否为仿真模式
  • 备份配置：设置页 →「备份 / 迁移」→ 导出任务航点 / 任务 / 定时（JSON）。换电脑时在新电脑上「导入 JSON」即可。
  • 完整备份：先从托盘退出程序，再复制整个 data 文件夹（程序运行时直接复制数据库可能得到不完整的副本）。
  • 磁盘占用：桌面版目前不会自动清理旧图片。可在「系统自检 → 媒体占用」查看；空间紧张时，退出程序后删除 data\media\runs\ 下较早的编号目录（只影响历史记录里那几次执行的图片显示）。

10更新与卸载

10.1 更新

  • 程序启动时会自动检查新版本；发现后在后台下载，下载完成会询问是否「现在重启安装」。若此时有巡检在执行，会先询问是否中止并停下机器人。
  • 也可以随时从托盘点检查更新…。没有新版本时会提示「已是最新版本」；暂时没有发布渠道时会提示「检查更新失败」，不影响使用。
  • 手动更新：直接运行新版本的安装包覆盖安装即可，数据与设置会保留。

10.2 卸载

  1. 先从托盘退出程序。
  2. Windows「设置 → 应用 → 已安装的应用」→ 找到 PatrolScheduler 0.8.0 → 卸载（或控制面板 → 程序和功能）。
  3. 卸载会删除程序文件和开始菜单、桌面快捷方式，但会保留 %APPDATA%\PatrolScheduler\ 里的数据与设置，重新安装后数据仍在。要彻底清除，卸载后手动删除该文件夹。

11安全须知（真机）

  1. 急停不是硬件急停，也不是锁：它让机器人端持续下发停止指令，现场遥控仍可能与之竞争，实测还有 5–7 秒滑行，而且不会取消云端任务。要确保绝对不动，请按物理急停按钮。
  2. 停任务 ≠ 停设备：停任务只让机器人停下，导航等模块还在运行（耗电）。当天收工时再按「停止设备（收尾 ⑧）」。
  3. 定位初值必须是机器人真实所在的航点，给错会导致巡检朝错误方向行走。
  4. 让机器人动起来之前，确认路径上没有人，并有人能随时按下物理急停。
  5. 同一时刻只有一方能控制机器人：现场人员可以抢走程序的控制权，程序不会反过来抢。看到「控制权被别人持有」时请等待，不要反复重试。
  6. 后台服务只监听本机（127.0.0.1），没有登录鉴权。请勿自行改成对局域网开放。
  7. 如果你的机器人别名接的是与真机共用 roscore 的仿真环境，不要按「启动设备 / 停止设备」。

程序启动失败：「后端 60 秒没起来」托盘或报错框里的日志目录，看 backend.out；常见原因是数据目录不可写或杀毒软件拦截

杀毒软件删除了程序文件把安装目录加入杀毒软件的排除项后重新安装
退出时卡了很久后台在等机器人确认停下（最多 40 秒），通常是云端不响应。超时后程序会强制结束

联系技术支持时请提供：托盘「状态…」的截图，以及日志目录里的 desktop.log、backend.out 和数据目录里的 logs\app.log。

一键灌入演示数据（仿真模式，可选）

在仿真模式运行时，打开 PowerShell 执行下面两行，会同步演示地图、建 3 个任务航点和 1 个任务，并跑一趟（约 40 秒）：

$R = "$env:LOCALAPPDATA\Programs\PatrolScheduler\resources"
& (Get-ChildItem "$R\runtime\python\*\python.exe" | Select-Object -First 1).FullName "$R\backend\scripts\seed_demo.py" --base http://127.0.0.1:8088 --reset --init --run --mock-speed 6

若端口不是 8088，把 --base 里的端口换成托盘「状态…」里显示的端口。
